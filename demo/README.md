# 本机演示样本

运行 `python demo/prepare_samples.py` 会从已下载的在线、离线模型目录读取上游测试 WAV，生成以下仅在本机使用的文件：

- `data/demo/speaker_a_enroll.wav`、`speaker_b_enroll.wav`：两段不同声音的注册样本。
- `data/demo/two-speaker-demo.wav`：甲、乙、甲、乙轮流讲话，中间各留 1 秒静音。
- `data/demo/two-speaker-demo.json`：源文件 SHA-256 和预期时间顺序。

样本音频及生成文件均不提交到 Git。两个声音的别名“甲/乙”只是演示标签，不代表录音者真实身份。上游模型测试录音的再分发条款需由使用方核查。

演示顺序：在网页“声纹人员”创建“示例甲”“示例乙”，分别上传对应注册样本；在“热词词库”创建并保存专有词；在“文件转写”上传拼接录音并选择热词方案，查看说话人时间轴，必要时修正错误标签，导出 JSON/TXT/SRT；最后在“实时识别”录入麦克风声音，观察临时文字、定稿和确认后的说话人标签。

当前两个来源的声纹余弦相似度在测试模型上约为 0.13，说明它们可用于测试“不同人”路径。离线分段模型仍可能漏检或把同一人拆成多个本地编号；必须使用人工标注的业务录音校准阈值后才能用于正式评估。此样本只验证流程，不作为识别准确率证据。
