# Mac 真模型 Demo 端到端验收（2026-10-25）

## 环境与范围

- 机器：Apple M4、10 核、16 GiB RAM，macOS Darwin 24.6.0 arm64；Python 3.11。没有 NVIDIA GPU。
- API 采用外置文件 Worker 模式；API 与唯一 Worker 分别在独立进程运行，共用本机 SQLite 和数据目录。在线、离线、声纹及离线分段模型按 `models/manifest.json` 的版本加载，`/ready` 返回 200。
- 输入为仓库内获准分发的 [AISHELL-3 双人样例](../demo_assets/aishell3/README.md)，约 7.049 秒。注册 A/B 时分别使用两份与待识别片段不同的同人录音。创建两词热词方案，并在任务中选择它。本次验证流程与功能，不代表业务录音准确率。
- 验收发生在实时最终片段的离线复识（T31）合入之前。实时单路结果只代表当时版本。

## 实测结果

| 步骤 | 结果 |
| --- | --- |
| 声纹注册 | 两位人员分别上传注册 WAV，服务均返回已注册。 |
| 文件任务 | 真实浏览器经页面内“载入双人样例”提交，外置 Worker 完成任务；另一路直接 HTTP 提交也成功。 |
| 说话人结果 | 四段时间依次约为 0.10–1.16、2.14–2.95、3.74–4.67、5.68–6.73 秒；两次提交均显示注册人员 A/B/A/B，四段均带已注册人员 ID。独立只读复核确认各时间段不重叠且在音频时长内。 |
| 页面显示 | 实际浏览器结果显示四段姓名、文字、时间，包含说话人纠错入口和 JSON/TXT/SRT 导出按钮。 |
| 导出接口 | 直接 HTTP 验证 JSON、TXT、SRT 均返回 200。 |
| 实时接口 | 将同一样例转换为 16 kHz 单声道 PCM16 后按 100 ms 帧同步发送；1/1 会话完成，4 个带说话人标签的 final 片段、3 次标签切换、0 服务端丢帧、0 客户端迟发帧；首个 partial 约 0.482 秒，stop→completed 约 0.018 秒。 |

浏览器内置样例需要先注册示例 A/B，才能显示对应姓名；没有注册时只能展示未知/本地说话人。浏览器工具提示 Ego Lite 可更新，本次未执行升级。实时结果和短样例的标签顺序不能推断长录音、噪声、重叠说话条件下的识别准确率。原始任务、音频副本和实时报告保存在本机未入库的 `data/baseline/integration-20261025/`。

## 小样本参考文字对照

用 AISHELL-3 发布的四句参考文字与源 WAV 拼接边界，对浏览器提交的文件结果运行 `evaluation.quality`：中文 CER 为 2/25 = **8.0%**；三处换人边界均找到，平均边界误差约 **0.205 秒**。工具给出的 DER-like 为 **35.9%**、注册人员命中时长比为 **64.1%**；参考标签和区间来自四段 WAV 的拼接顺序与拼接点，并非人工声学边界标注；DER-like 与注册命中只按这组参考语音区间计时，受源片段首尾停顿和模型检测区间影响，不能解释为真实声学分段或业务准确率。样本没有未知人员或目标热词，相关指标为不可评估。四句不足以估计实际业务场景的 CER 或声纹准确率。

另建一套热词方案，先加入“玩儿”，再编辑成 v2，加入“桌上”；对同一公开样例各提交一次无热词/有热词文件任务。两次任务都成功，有热词任务记录固定版本 **v2**。参考文字对照显示 CER **2/25（8%）→1/25（4%）**，“玩儿”“桌上”的目标词命中 **1/2→2/2**。评估输入中的 `hotwords_enabled` 由这两次已知的任务参数补充，原始服务结果没有该布尔字段。参考中没有不应出现的目标词，误插入率分母为零，标记为**不可评估**。这条短样例只证明热词编辑、版本固定与原生热词解码在真实模型上可运行，不代表普遍准确率收益。

## 实时离线复识与无静音换人复测

在最终版独立实时离线复识进程中，同一 WebSocket 会话收到在线 `partial`、在线 `final`，随后收到相同 `segment_id` 且 `revision` 更高的离线 `final`；最后一个修订先于 `completed`。`/ready` 对实时离线复识子进程返回就绪。单路 350 ms 间隔样例完成 4 个带注册姓名的最终片段，3 次换人，0 服务端丢帧。

另将四条官方源 WAV 直接拼接，**不插入额外静音**，得到约 5.999 秒的本机检查音频。文件模式仍输出四段 A/B/A/B；初版实时路径只输出三段，末尾 B 的文字被错误合并到 A。修复会话结束时的待定换人确认后，在当前主线重放，实时输出 **4 个不重叠的 final 片段**：约 0–1.5 秒 A、1.5–3.0 秒 B、3.0–4.5 秒 A、4.5–6.0 秒 B，最终事件后收到 `completed`，无错误。第四句仍有一处 ASR 字词差异，分段正确不等于逐字准确。此检查只有两位已注册人员的四句短音频，短尾音、未知人、噪声和重叠说话的业务表现仍需标注样本评估。原始前后事件留在本机 `data/baseline/integration-20261025/`，不随仓库发布。
